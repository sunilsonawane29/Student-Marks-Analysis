# Student Marks Analysis Using Python

## Project Overview
Student Marks Analysis is a beginner-friendly data analysis project built using Python and Pandas. It analyzes students' marks in Python, SQL, and Excel to calculate average scores and determine pass or fail results.

## Features
- Stores student marks in a structured dataset.
- Calculates each student's average marks.
- Determines pass or fail based on an average score of 40.
- Calculates the overall class average.
- Counts the number of students who passed and failed.
- Exports the analysis results to a CSV file.

## Technologies Used
- Python
- Pandas
- CSV

## Project Files
- `Student_analysis.py` — Python script for analyzing student marks.
- `student_analysis.csv` — Dataset containing the analysis results.
- `README.md` — Project documentation.

## How to Run the Project

### 1. Install Python
Download Python from https://www.python.org/downloads/ if it is not already installed.

### 2. Install Pandas
```bash
python -m pip install pandas
```

### 3. Run the Script
```bash
python Student_analysis.py
```

### 4. View the Results
The program displays individual student averages, pass/fail results, class average, and pass/fail counts in the terminal. It also generates `student_analysis.csv`.
