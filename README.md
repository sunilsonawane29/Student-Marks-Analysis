
# Student Performance Analysis Using Python

## Project Overview
A beginner-friendly data analytics project that explores
student academic performance using Python.

## Objectives
- Analyze student marks and attendance.
- Explore the relationship between study hours and marks.
- Identify missing values and duplicate records.
- Create visualizations and summarize findings.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Git and GitHub

In progress.
